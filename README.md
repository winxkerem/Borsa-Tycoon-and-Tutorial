# Borsa Tycoon and Tutorial
Python dili kullanılarak geliştirildi ve antigravity tarafından yardım alınarak oluşturuldu
## 🚀 Projenin Amacı ve Özellikleri
Proje, kullanıcıların sanal bir bakiye ile canlı akan finansal piyasalarda alım-satım yaptıkları bir oyundur.
* **Canlı Zaman Simülasyonu:** Her 5 saniyede bir sayfa yenilenmeden fiyatlar güncellenir.
* **Yapay Zeka Danışmanı:** Kullanıcıya dinamik yatırım stratejileri fısıldar.
## 🛠️ Kullanılan Teknolojiler
* **Backend:** Python 3.11 / Flask 3.x
* **Veritabanı:** SQLite / SQLAlchemy 2.x
